# 인물 사진

사용자가 제공한 사진(1장에 3명)을 인물별로 잘라 사용합니다.

| 파일 | 영상 속 인물 |
|---|---|
| face_A.jpg / persona_A.jpg | 김지원 (은퇴 강사·자문가) |
| face_B.jpg / persona_B.jpg | 박서연 (카페 사장님) |
| face_C.jpg / persona_C.jpg | 이도윤 (프리랜서) |

- `face_*.jpg`: 정사각형 얼굴 사진입니다. 후킹·명함·폰·클로징의 동그라미에 쓰입니다.
- `persona_A.jpg`: 프로필 사진 장면의 "내 사진 한 장" 카드에 쓰입니다.
- 사진을 바꾸려면 같은 이름으로 덮어쓰고 다시 렌더링하면 됩니다.
- `old_stock/`: 이전에 임시로 쓴 Pexels 사진입니다. 지금은 쓰지 않으며, 지워도 됩니다.
